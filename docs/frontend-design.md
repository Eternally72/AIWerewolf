# Frontend Design

前端使用 Vue 3 + TypeScript + Pinia + Vue Router。

## 页面

- 首页：项目入口和特色展示。
- 创建房间页：模板、角色计数、规则和观众视角配置。
- 大厅页：座位和开始按钮。
- 游戏主页面：环形座位、阶段、公开发言、时间线。
- 上帝视角：完整身份、阵营、时间线和快进控制。
- 结束页：结算和回放入口预留。

## 风格

暗夜、月光、圆桌、推理桌游氛围。图片未提供时使用 CSS 渐变和首字母/座位号头像作为 fallback。

## 状态同步

页面加载时通过 REST 恢复状态；运行中通过 STOMP 订阅公共、阶段、时间线和 GodView 频道。断线后自动重连。
